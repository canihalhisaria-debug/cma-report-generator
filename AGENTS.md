# AGENTS.md

## Rules
- Preserve Excel formatting and sheet structure.
- Do not redesign sheets unless necessary.
- Always work in a fix-check-fix loop.
- After every fix, run validation again.
- Check Projected P&L, Projected Balance Sheet, ratios, working capital, stock flow, CC interest logic, and net worth linkage.
- Prefer small safe edits.
- Stop only when no material issue remains or only manual assumption decisions remain.
- Always give a final summary of issues found, fixes applied, files changed, and unresolved items.
